# Migrating to Spring Boot 4

After the release of Spring Boot 4, this project examples will be updated to the lastest version of Spring Boot 4.x.x. I will migrate those projects step by
step and take advantage of the new features and improvements introduced in Spring Boot 4.

> Those projects are for study purposes and to share knowledge with the community. They may not be production-ready and could lack certain best
> practices or optimizations.
